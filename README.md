**Medicine Scanner & AI Health Assistant App**

A full-stack application that scans medicines, suggests generic alternatives, and helps locate nearby stores/doctors. Includes an AI chatbot for interpreting symptoms and offering basic guidance. Containerized with Docker, deployed via Jenkins, with Kubernetes explored for orchestration and Prometheus/Grafana for monitoring.

```
User → Frontend → Node.js / Express → MongoDB → AI Service

Docker → Jenkins → Kubernetes
                 ↓
        Prometheus + Grafana
```

`HTML` `CSS` `Bootstrap` `JavaScript` `Node.js` `MongoDB` `Docker` `Kubernetes` `Jenkins` `Prometheus` `Grafana`
